# 🌐 Cómo subir tu web a GitHub (Hello Chicos)

Tenés **un solo archivo**: `index.html` (con todas las imágenes adentro).
Es autónomo: se abre en cualquier compu y muestra todo, sin archivos extra.

## Opción A — Publicarla GRATIS con GitHub Pages (recomendado)

1. Entrá a https://github.com y creá una cuenta (si no tenés).
2. Botón **New repository** → ponele un nombre (ej. `hello-chicos`) → **Public** → **Create**.
3. En el repo: **Add file → Upload files** → arrastrá `index.html` → **Commit changes**.
4. Andá a **Settings → Pages**.
5. En "Branch" elegí **main** y carpeta **/ (root)** → **Save**.
6. Esperá 1-2 minutos. Arriba te aparece el link público:
   `https://TU-USUARIO.github.io/hello-chicos/`

¡Listo! Esa es tu página online, gratis.

## Opción B — Solo guardar el código
Subí `index.html` al repo y ya queda versionado. Podés abrirlo local con doble clic.

## Antes de publicar, revisá:
- 🔗 Los botones "Descargar" tienen `href="#"`. Cambialos por el link real de tu
  producto (Shopify/Mercado Pago) para que se pueda comprar.
- ⭐ Las reseñas usan fotos y nombres de ejemplo. Cambialas por reseñas reales
  cuando las tengas.
- 📝 En la imagen del Mega Pack hay palabras en inglés mal escritas (de la IA).
  Conviene regenerarla con el texto correcto.

## ¿Necesitás cambiar una imagen más adelante?
Como están incrustadas, avisame y te regenero el `index.html` con la nueva imagen.
